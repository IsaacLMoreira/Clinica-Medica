# Sistema de Clínica Médica — Java Swing

Projeto acadêmico desenvolvido para a disciplina de **Linguagem de Programação II**, lecionada por **Cleber Jorge Lira de Santana**, com foco em interfaces gráficas em Java Swing, utilizando as arquiteturas **SDI (Single Document Interface)** e **MDI (Multiple Document Interface)**.

O sistema realiza operações de cadastro, consulta, alteração, exclusão e listagem de pacientes, com persistência dos dados em banco **PostgreSQL**.

## Funcionalidades

- Cadastro de pacientes;
- Consulta por nome ou CPF;
- Listagem utilizando `JTable`;
- Alteração de registros;
- Exclusão de registros;
- Interfaces SDI e MDI;
- Persistência dos dados em PostgreSQL.

Cada paciente possui:

```text
Código
Nome
CPF
Data de nascimento
Telefone
E-mail
Convênio
```

O código é gerado automaticamente pelo banco de dados.

## Banco de dados

O projeto utiliza um banco PostgreSQL local. Mas foi padronizado em:

```text
Host: localhost
Porta: 5432
Banco: clinica_medica
Usuário: postgres
Senha: gta6emnovembro
```

A conexão é realizada através de:

```text
jdbc:postgresql://localhost:5432/clinica_medica
```

A configuração está localizada em:

```text
repository/ConnectionFactory.java
```

### Tabela utilizada

```sql
CREATE TABLE pacientes (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    cpf VARCHAR(14) NOT NULL UNIQUE,
    data_nascimento DATE NOT NULL,
    telefone VARCHAR(20),
    email VARCHAR(150),
    convenio VARCHAR(100)
);
```
### Consultar Tabela no Postgres

```sql
SELECT * FROM pacientes;
```

## SDI e MDI

Na versão **SDI**, cadastro e consulta são abertas como janelas independentes utilizando `JFrame`.

```text
TelaPrincipal
   ├── CadastroPacienteSDI
   └── ConsultaPacienteSDI
```

Na versão **MDI**, existe uma única janela principal com um `JDesktopPane`, no qual são abertas as janelas internas através de `JInternalFrame`.

```text
TelaPrincipalMDI
       │
   JDesktopPane
       ├── CadastroPacienteMDI
       └── ConsultaPacienteMDI
```

As duas interfaces utilizam o mesmo backend e o mesmo banco de dados.
